# Crates

* [okft-core](okft-core.md) - Parsing, the conformance validator, the lint registry, and the link graph.
* [okft](okft.md) - The `okf` binary that wraps the core and renders diagnostics.
* [okft-mcp](okft-mcp.md) - An MCP server exposing a bundle to AI agents.
* [okft-web](okft-web.md) - A self-contained local graph viewer.

# Distribution

* [github-action](github-action.md) - The composite action that runs `okf validate` in any repository.
