# Crates

* [okf-toolkit-core](okf-toolkit-core.md) - Parsing, the conformance validator, the lint registry, and the link graph.
* [okf-toolkit-cli](okf-toolkit-cli.md) - The `okft` binary that wraps the core and renders diagnostics.
* [okf-toolkit-mcp](okf-toolkit-mcp.md) - An MCP server exposing a bundle to AI agents.
* [okf-toolkit-web](okf-toolkit-web.md) - A self-contained local graph viewer.

# Distribution

* [github-action](github-action.md) - The composite action that runs `okft validate` in any repository.
